# KartHub Alpha - Production Ready

## Locale
npm install
npm run dev

## Build
npm run build
npm run preview

## Pubblicazione Vercel
1. Aprire https://vercel.com/drop
2. Trascinare la cartella estratta del progetto
3. Scegliere nome progetto e Deploy

In alternativa: npm install -g vercel && vercel --prod

## Limiti Alpha
Gare, ranking, mappa e profilo sono dati dimostrativi. Nessun login, pagamento o booking reale è attivo.
